# aocds
My own implementation of almost all kinds of data structures and algorithms in C

Work in progress...  :
- Sinlgy and doubly circular multi-typed linked lists

Assumptions:
Every data structure supports the following types:
Fundamentals: 
    - short
    - ushort
    - int
    - uint
    - char
    - uchar
    - long
    - ulong
    - long long
    - ulong long
    - float
    - double
    - long double
Others(Mapped to fundamentals):
    - int8_t
    - uint8_t
    - int16_t
    - uint16_t
    - int32_t
    - uint32_t
    - int64_t
    - uint64_t
Custom data types --> All stored records have to be alive, you can only store a pointer to them inside the ds in this library!!!
